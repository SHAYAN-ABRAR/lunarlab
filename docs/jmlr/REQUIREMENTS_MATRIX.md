# JMLR-MLOSS requirements and venue fit

Checked 19 October 2026 against the official [MLOSS instructions](https://www.jmlr.org/mloss/mloss-info.html), [author information](https://www.jmlr.org/author-info.html), [format instructions](https://www.jmlr.org/format/format.html), and [authors guide](https://www.jmlr.org/format/authors-guide.html).

## Venue constraints

| Constraint | Finding and evidential scope |
|---|---|
| Legitimate peer-reviewed journal | JMLR describes editor screening, an action editor and written technical reviews. MLOSS is its research-software track |
| Q1 | [SCImago's JMLR record](https://www.scimagojr.com/journalsearch.php?q=20969&tip=sid) reports SJR 2025 = 1.997 and best quartile Q1; listed relevant categories include Artificial Intelligence and Software. This is Scopus-based SJR, not a claim of a separately verified Clarivate JCR quartile |
| Publication fees / APC | The official author page explicitly states no publication fees |
| Submission fee | No submission charge or payment step is prescribed in the published submission procedure. The page's explicit zero-fee sentence concerns publication; a separate explicit zero-submission-fee sentence was not located |
| Interview / oral presentation / conference appearance | None is required by the published JMLR-MLOSS submission/review procedure. Optional journal-to-conference presentation opportunities are a separate route and are unnecessary here |
| Route | Keep JMLR-MLOSS. Do not substitute JOSS, TMLR or PMLR conference proceedings |

## Submission requirements versus review expectations

| Item | Status | Classification |
|---|---|---|
| Public source; recognized open-source license and clear component notices | Public MIT source, SPDX and third-party notices present | Submission requirement |
| Description up to four pages, references additional; official JMLR style | Revised paper built and checked; see BUILD.md for actual page QA | Submission requirement |
| Cover letter: MLOSS designation, license, URL, review version, community evidence | Draft supplied; community and human confirmations unresolved | Required submission material |
| Software runs on declared platforms; clean source archive | Published Linux/Windows and fresh-install CI verified; final revised source needs its own release gate | Submission checklist |
| Research significance, comparison, runtime/memory, docs, extensibility, tests, coverage, CI, openness | Substantial evidence; limitations described in review | Review criteria, not a list of independent eligibility cutoffs |
| Active community | No independent use established; truthful disclosure required | Explicit cover-letter item and major impact criterion; no published numeric minimum |
| Release tag, DOI, hosted docs, extra environments, matched-budget algorithms | Helpful where justified | Best practices or optional improvements, not invented mandatory rules |

The general author rules also apply: PDF, complete corresponding-author information, short running title, five keywords, abstract at most 200 words, author consent, overlap/conflict disclosures, editor/reviewer suggestions, and funding/competing-interest statements. The general long-paper guidance does not override the four-page MLOSS description limit. Do not label review criteria as all-or-nothing eligibility rules, or mark unresolved evidence as complete.
